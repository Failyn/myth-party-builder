# Myth Party Builder

Party builder and Odyle energy tracker for a small AION 2 group.

- `index.html` is the whole page. It is built from a separate source file; edit that and rebuild, do not edit this file by hand.
- `roster.json` lists the characters. Add or remove an entry to change who is tracked.
- `scripts/refresh.py` reads item level and combat power from the official character pages and writes them to the shared database. `.github/workflows/refresh.yml` runs it every hour.

Viewing needs no login. Editing parties and energy needs the group passcode, entered on the page with "Unlock editing".
